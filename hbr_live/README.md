# HBR Live · 星屑战斗手帐

独立的 Windows 内存只读战斗助手，含本地星屑资料室。整个文件夹可以单独移动使用。
不依赖上级目录，不包含 OCR、截屏、图像识别模型或旧挂件。

## 开始

安装 Python 3.12（含 Tk），在此目录执行 `python -m pip install -r requirements.txt`。
双击 **启动HBR Live.bat**，接受管理员权限提示。启动器优先使用本机 `F:\python\pythonw.exe`，否则查找 PATH。
先停在战斗指令选择画面，点击 **连接战斗**，等“内存已连接 · 可以行动”后攻击。
第一次扫描一般需要几十秒。权限不足、版本布局不兼容、多个战斗对象无法区分时会明确提示。

## 面板

- 窗口可随时拖动、缩放；设置菜单提供紧凑模式、置顶、透明度，退出时保存布局。
- 左侧选择敌人，查看实际 DP/HP。资源回升直接反映在量表中，回升次数只是观测记录，**不代表盾条数或锁盾状态**。
- 量表参考值是连接以来观测的最大值，不冒充怪物配置最大值。中途连接不会还原历史伤害。
- 右侧每笔行动只计一次，后续命中更新同一笔；选中查看本体、连击珠、暴击与目标，双击独立展开。
- 伤害保留显示值及过量伤害；DP/HP 使用游戏实值，两者不互相推算。
- 暂停用于思考，暂停期间请勿行动。恢复后沿用当前统计；暂停期间执行并消失的行动无法补回。
- 每场需重新连接。连接失败时保留上场结果，成功后开始新的统计。

## 资料和记录

星屑资料室在独立窗口中打开，保留头像、结构化技能明细、敌人资料和只读 SQL 查询。
本机已复制现有资料和头像快照到 `data/quest`，不需要重新下载。缓存不进入 Git；全新克隆可在资料室内同步。
战斗数据自动保存到 `sessions/*.jsonl`，菜单可导出一份当前摘要。诊断默认隐藏。
停止/关闭会等待读取线程退出并关闭日志文件。

## 边界与开发

仅使用 Windows 查询/读取权限，不注入、不修改游戏内存或文件。已验证国服 6.5.10 的运行时布局。
锁 DP 时只展示读到的实际值，不自行解除锁定、不推测状态名称。多敌人和特殊效果仍需逐场验证。
不会自动选择多个残留战斗对象中的一个，必要时重启游戏后重新连接。

运行：`python -B -m hbr_live_app`（终端需管理员权限才能读管理员游戏）。
测试：`python -B -m unittest discover -s tests`。

模块分工：`runtime` 只读系统接口；`source` 定位与采样；`events` 行动归并；
`model` 面板状态；`app` 窗口；`hbr_data` 独立资料接口。事件包含命中明细，为后续分析保留接口。
